1. このアプリについて

「フォーメーション練習」は、ダンサーの立ち位置や動きを画面で確かめる練習アプリです。

運営する人：準備中

2. 集める物・集めない物

集めない物

このアプリは、次の物を集めません。送りません。

  • お名前・メールアドレス・電話番号・住所
  • 位置情報
  • アクセス解析・広告のための情報（そのための部品は入れていません）
  • ログイン情報（このアプリにログインはありません。Google や YouTube のアカウントにもつながりません）

端末の中だけに置く物

次の物は、お使いの端末（iPhone や Android のブラウザー）の中だけに保存します。運営する人のところには届きません。ほかのサーバーにも送りません。

物中身消えるとき
作った作品隊形・人の名前・ステージの大きさ・照明のきっかけなど作り直すまで残る
自分の選び・向きの選び「自分」にした人の番号・客席から／ダンサー目線変えるまで残る
YouTube の動画の番号入れた URL の中の11文字の動画 ID だけ（別のしまい場所）「動画を閉じる」を押すと消える
同意の印YouTube の動画を使うことに同意した日付だけ（別のしまい場所。作品には入りません）端末のデータを消すまで残る
読めなかった作品の写し起動のとき読めなかった保存データを、そのまま3件まで古い物から入れ替わる
  • 曲のファイルは、端末の中だけで解析します。どこにも送りません。曲は保存しません（開き直したら読み込み直します）。
  • 「ファイルに保存」「画像に書き出す」「動画に書き出す」は、押したときだけ、端末にファイルを作ります。それを誰に渡すかは、お使いの方が決めます。

3. YouTube の動画を使うとき

いつ YouTube につながるか

設定タブで YouTube の URL を入れて「動画を出す」を押したときだけ、YouTube（運営は Google）につながります。動画を出さないあいだは、YouTube にまったく通信しません。開き直しても、前の動画は自動では出ません。動画は自動では再生されません。再生ボタンを押したときだけ再生します。

初めて動画を出すときに、この文書と YouTube の利用規約を読んで同意するかを、1回だけ確かめます。

使っている仕組み

  • このアプリは YouTube API サービス（YouTube の埋め込みプレーヤーと IFrame Player API） を使っています。
  • 動画の枠は、YouTube の「プライバシー強化モード」の埋め込み（youtube-nocookie.com）です。YouTube のヘルプでは、この方式だと「埋め込み動画を見たことが、YouTube でのおすすめの表示に使われない。広告も、個人に合わせた広告にならない」と説明されています。

YouTube に送られる物

動画の枠が読み込まれると、YouTube の仕組みにより、YouTube（Google）にお使いの端末の基本的な情報が送られます。YouTube の開発者向けの決まりには、次のように書かれています。

  • 枠を読み込んだとき：動画の題名や画像を出す・再生できるかを調べる・不正を防ぐために、基本的な利用者の情報が YouTube と共有される。
  • 動画を再生したとき：プレーヤーを整えるために、さらに情報が集められ共有される。

何が送られるかの細かい一覧は、YouTube の側が決めています。このアプリは、YouTube に作品・曲・名前・動画の ID の保存内容を送りません（プレーヤーに動画の ID を伝えるのは、動画を出すためです）。

端末への保存・広告について

  • YouTube の枠は、端末に Cookie など、情報を保存したり読み出したりする仕組みを使うことがあります。
  • YouTube の動画には、広告が出ることがあります。広告は YouTube（Google）が出すもので、このアプリは広告を出しません。

YouTube の規約と Google のプライバシーポリシー

  • このアプリの動画の機能を使うと、YouTube の利用規約に同意したことになります。YouTube 利用規約
  • YouTube を通じて集められる情報の扱いは、Google のプライバシーポリシーに書かれています。Google のプライバシーポリシー

子ども向けの動画

YouTube には「子ども向け」と表示された動画があります。このアプリは、どの動画が子ども向けかを調べていません。

4. 端末のデータの消し方

消すと、作品も消えます。戻せません。先に「ファイルに保存」で書き出してください。

アプリの中で消せる物

  • YouTube の動画の番号：設定タブの「動画を閉じる」
  • 作品：設定タブの「見本の作品に戻す」（今の作品が見本に置き換わります。「元に戻す」で戻せるのは、アプリを閉じるまでです）
  • 同意の印・読めなかった作品の写し：アプリの中に消すボタンはありません。下の端末の操作で消してください（同意の印を消すと、次に動画を出すとき、もう一度同意を確かめます）。

全部まとめて消す

  • iPhone（Safari）：「設定」→「アプリ」→「Safari」→「詳細」→「Webサイトデータ」→「すべてのWebサイトデータを削除」（画面の文字は、iOS の版で少し違います）
  • ホーム画面に追加したアプリの場合：消し方は準備中です。上の Safari の操作で消えるかは、まだ確かめていません。
  • Android（Chrome）：Chrome の「設定」→「プライバシーとセキュリティ」→「閲覧履歴データの削除」→「Cookie とサイトデータ」にチェック→「データを削除」（画面の文字は版で違います）

YouTube の側に残る情報（YouTube を見たときの記録など）は、Google のアカウントの設定から確かめます。Google のプライバシーポリシー
